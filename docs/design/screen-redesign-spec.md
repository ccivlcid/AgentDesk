## 화면 01 — AppHeaderBar (전역 상단 바)

### 현재 상태

```
┌──────────────────────────────────────────────────────────┐
│  [Logo]  AgentDesk                    [알림] [업데이트]    │
└──────────────────────────────────────────────────────────┘
```

현재 문제:
- `Cmd+K` 커맨드 팔레트 없음 — 파워유저 진입점 부재
- 헤더 배경색 일관성 부족
- 뷰 제목이 헤더가 아닌 각 화면에 분산됨

### 변경 후

```
┌──────────────────────────────────────────────────────────┐
│  ▶  AgentDesk   [Alpha Project ▾]     [⌘K Search...]  [🔔]│
└──────────────────────────────────────────────────────────┘
```

| 요소 | 현재 | 변경 후 |
|------|------|---------|
| 로고 | 이미지/텍스트 | `▶ AgentDesk` (amber `▶` + bold sans) |
| 프로젝트 선택기 | 사이드바에만 있음 | 헤더 중앙-좌측에 `[Project Name ▾]` 상시 노출 |
| 커맨드 팔레트 | 없음 | `[⌘K Search...]` 버튼 — 클릭 또는 `Cmd+K`로 열림 |
| 알림 | 아이콘 버튼 | 유지, 스타일 통일 |
| 업데이트 알림 | 배너 형식 | 알림 아이콘 내 뱃지로 통합 |
| 배경 | `var(--th-bg-elevated)` | 유지 |

## 화면 03 — 대시보드 Overview (Dashboard — Overview tab)

### 현재 상태

실제 `Dashboard2.tsx` 코드 기준 레이아웃 — **세로 스택 구조**:

```

│                                          [+ Task] [→보드]  │
├────────────────────────────────────────────────────────────┤
│  [개요]  [프로젝트 설정]  [프로젝트 유형]                     │  ← 탭 (한글)
├────────────────────────────────────────────────────────────┤
│                                                            │
│  ┌──────────────────────┬──────────────────────┐           │
│  │  Goals          ?    │  Risks          ?    │           │  ← 2×2 QuadPanel
│  │  ────────────────    │  ──────────────────  │           │    그리드
│  │  (목표 리스트)         │  (리스크 리스트)        │           │
│  ├──────────────────────┼──────────────────────┤           │
│  │  Gates          ?    │  Outputs        ?    │           │
│  │  ────────────────    │  ──────────────────  │           │
│  │  (검토 리스트)         │  (결과물 리스트)        │           │
│  └──────────────────────┴──────────────────────┘           │
│                                                            │
│  ┌────────────────────────────────────────────┐            │  ← TeamPanel
│  │  PROJECT TEAM                              │            │    (2×2 아래에
│  │  🤖 Alpha  🤖 Beta  + Add Agent           │            │     세로로 위치)
│  └────────────────────────────────────────────┘            │
│                                                            │
│  ┌────────────────────────────────────────────┐            │  ← AgentActivityPanel
│  │  AGENT ACTIVITY                            │            │    (에이전트 배정 시만
│  │  [미니 터미널: 최근 CLI 출력 8줄]             │            │     표시)
│  └────────────────────────────────────────────┘            │
│                                                            │
└────────────────────────────────────────────────────────────┘
  ↑ 스크롤 없이 전체 보이지 않음 — TeamPanel / AgentActivityPanel은 화면 밖
```

현재 문제:
- **레이아웃 구조적 문제**: TeamPanel + AgentActivityPanel이 2×2 그리드 **아래에** 세로로 쌓여 있어 스크롤 없이 보이지 않음
- `AgentActivityPanel`: 팀에 에이전트가 없으면 렌더링 자체를 숨김 → 존재 자체가 비가시적
- `core_goal`(핵심 목표) 헤더에 미표시
- 헤더 stat 배지에 `rounded` 클래스 (CLI 스타일 위반)
- `TeamPanel` outer div에 `rounded` 클래스
- `TeamPanel` 팀원 아바타 태그에 `rounded` 클래스
- `AgentActivityPanel` outer div에 `rounded` 클래스, 미니 터미널에 `borderRadius: 4`
- 빈 상태 버튼 `borderRadius: "2px"` (불일치)
- 탭 레이블 한/영 혼용: `개요`, `프로젝트 설정`
- `LoadingPlaceholder`에 `rounded` 클래스

### 변경 후

**2컬럼 레이아웃** — 왼쪽(메인 QuadPanel) + 오른쪽(260px 사이드바):

#### 오른쪽 사이드바 — AGENT ACTIVITY 패널

```
AGENT ACTIVITY                        ← 9px uppercase mono, muted
────────────────────────────────
(미니 터미널 출력 영역)
  alpha [03:22] > step 3/7: lint
  alpha [03:23] > output: OK
  alpha [03:23] > step 4/7: test
  beta  [02:10] > idle, waiting
  ...                                 ← JetBrains Mono 11px
                                      ← 최대 8줄, 넘으면 상단 잘림
────────────────────────────────
last updated 3s ago                   ← 11px muted, 폴링 타임스탬프
```

**표시 조건**:
- 팀에 에이전트가 1명 이상 있을 때만 표시
- 팀에 아무도 없으면: `"No agents in team"` 빈 상태 (숨김 아님)

**데이터 소스**:
- WebSocket `cli_output` 이벤트 구독 (실시간)
- 3초 폴링 fallback (`fetchRecentActivity`)
- 각 에이전트 최근 3개 로그 라인 병합

| 요소 | 현재 | 변경 후 |

| TeamPanel 위치 | 2×2 그리드 아래 스크롤 필요 | 오른쪽 사이드바 상단 — 항상 가시적 |
| AgentActivityPanel 위치 | 2×2 + TeamPanel 아래 (스크롤 밖) | 오른쪽 사이드바 하단 — 항상 가시적 |
| AgentActivityPanel 빈 상태 | `return null` (숨김) | `"No agents in team"` 빈 상태 표시 |
| 팀원 표시 | 아바타 태그 `rounded` | `rounded: 0` + 상태 배지 inline |
| 팀원 추가 | 버튼 클릭 | 팝오버 피커 (검색 + 목록) |

| 상태 요약 | 헤더 우측 `rounded` 배지 | 탭 위 상태 바 1줄 (mono, `border-bottom`) |
| 탭 레이블 | `개요` `프로젝트 설정` | `OVERVIEW` `PROJECT SETTINGS` `PROJECT TYPES` |
| 패널 제목 | 한글 혼용 | `GOALS` `RISKS` `GATES` `OUTPUTS` (영문 uppercase) |
| 상태 배지 스타일 | 혼용 | mono font, `border-radius: 0`, `--th-*` 색상 |
| progress % | hover에만 | **항상 표시** (오른쪽 정렬, mono) |
| `rounded` 제거 대상 | stat badges, TeamPanel, AgentActivity, placeholder | **모두 `0`으로 통일** |
| `?` 버튼 | 이미 존재 | 유지 + 스타일 통일 (`border-radius: 0`) |
