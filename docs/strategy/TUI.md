  개선 포인트

  1. 실패한 태스크를 확인할 방법이 없음 (심각)
  사이드바에 [!] 아이콘은 뜨지만, 왜 실패했는지 TUI에서 볼 수 없음. GUI는 FAILED 배지 클릭 → 해당 태스크로 포커스. TUI는 서버 로그 직접 확인해야 함.

  2. 태스크 라이브 출력 불가
  GUI Timeline 탭엔 태스크별 WebSocket 스트리밍이 있음. TUI는 사이드바 상태(done/in_progress)만 보임. 에이전트가 지금 뭘 하는지 전혀 안 보임.

  3. Tab 모드 토글이 yolo를 건너뜀
  // App.tsx:108
  setMode((prev) => (prev === "plan" ? "build" : "plan"));
  plan ↔ build만 순환. yolo는 자연어로만 설정 가능. 개발자 입장에서 yolo 모드가 중요한데 접근이 불편.

  4. 프로젝트 전환 없음
  현재 세션에 projectId가 하나만 묶임. 다른 프로젝트 상태 확인하려면 TUI를 재시작하거나 /new로 새 세션 생성해야 함.

  5. 사이드바 branch가 항상 null
  // useSidebar.ts:46
  project = { name: p.name, path: p.project_path, branch: null };
  branch 정보를 아예 API에서 안 가져옴. 개발자가 어느 브랜치에서 실행 중인지 중요한 정보.

  6. 태스크 8개 제한 + 스크롤 없음
  사이드바 태스크 최대 8개 표시, 그 이상은 +N more. 클릭도 스크롤도 불가.

  7. 사이드바 새로고침이 30초
  WS 이벤트가 오면 즉시 갱신되지만, 초기 연결 직후 또는 WS 이벤트가 없는 상황에서는 30초간 stale한 상태.

  8. 킥오프 후 pipeline 사라짐
  stage가 "done"이 되면 pipelineStage가 null로 안 바뀌지만, 신규 프로젝트 시작 시 이전 파이프라인이 남아있음.
