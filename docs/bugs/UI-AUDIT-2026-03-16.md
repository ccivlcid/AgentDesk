#### [WB-01] ❌ Condition 노드가 런타임에 실제로 실행되지 않음

**파일:** `src/components/workflow-builder/WbRunModal.tsx`
**위치:** 라인 60, `resolveAgentDeps()` 함수 (라인 29-53)

**현재 동작:**
```typescript
// 라인 60: agent 타입 노드만 Task로 생성함
const agentNodes = nodes.filter((n) => n.type === "agent");
```
Condition 노드는 **의존성 경로 BFS 추적에만** 사용됨.
실제로 A→Condition→B 경로가 있을 때 Condition의 `expression` 필드는 완전히 무시됨.

**영향:** 사용자가 Condition 노드에 표현식을 입력해도 항상 모든 하위 에이전트가 실행됨. 조건 분기 기능 사용 불가.

**수정 방향 (설계):**
1. DB: `tasks` 테이블에 `gate_condition TEXT` 컬럼 추가 (마이그레이션)
2. WbRunModal: Condition 노드 expression을 선행 Task의 `handoff_condition`으로 저장
3. `run-complete-handler`: 완료 시 `gate_condition` 평가 후 후속 Task 생성/스킵

#### [WB-02] ⚠️ 의존성 연결 실패 시 롤백 없음

**파일:** `src/components/workflow-builder/WbRunModal.tsx`
**위치:** 라인 140-154

**현재 코드:**
```typescript
for (const [fromIdx, toIdx] of agentDeps) {
  try {
    await fetch(`${API}/tasks/${createdIds[toIdx]}/dependencies`, {
      method: "POST",
      body: JSON.stringify({ depends_on_task_id: createdIds[fromIdx] }),
    });
  } catch {
    addLog(`  ✗ ${t({ ko: "의존 관계 설정 실패", en: "Dependency setup failed" })}`);
  }
}
```

**문제:** 의존성 연결이 실패해도 이미 생성된 Task들은 그대로 남음. 에이전트들이 의존성 없이 독립 병렬 실행됨.

**수정 방법:** 의존성 설정 실패 시 생성된 모든 Task를 삭제하는 롤백 처리.

```typescript
// Phase 3: 실패 시 롤백
if (hasDepError) {
  addLog(t({ ko: "⚠ 의존 관계 설정 실패 — 생성된 태스크를 정리합니다...", en: "⚠ Rolling back created tasks..." }));
  await Promise.allSettled(
    createdIds.filter(Boolean).map((id) =>
      fetch(`${API}/tasks/${id}`, { method: "DELETE" })
    )
  );
  setPhase("config");
  return;
}
```

#### [WB-03] ⚠️ Trigger 노드 타입 정보가 Task에 저장되지 않음

**파일:** `src/components/workflow-builder/WbRunModal.tsx`
**위치:** 라인 95-130

**현재 코드:**
```typescript
body = {
  title: item.taskTitle,
  assigned_agent_id: item.agentId,
  status: "planned",
  ...(projectId ? { project_id: projectId } : {}),
  ...(item.instruction ? { description: item.instruction } : {}),
};
```

**문제:** `context_hint`(workflow pack key), trigger 타입(`webhook`/`scheduler`/`messenger`)이 Task에 전달되지 않음.
Task 실행 시 어떤 Workflow 맥락에서 왔는지 추적 불가.

**수정 방법:** Trigger 노드 데이터를 부모에서 WbRunModal로 전달하고 Task에 `context_hint` 추가.

```typescript
// Trigger 노드 찾기
const triggerNode = nodes.find((n) => n.type === "trigger");
const triggerType = (triggerNode?.data as any)?.triggerType ?? "manual";

// Task 생성 시 포함
body = {
  ...body,
  context_hint: triggerType,  // "manual" | "schedule" | "webhook" | "messenger"
};
```

// 엣지 생성 (기존 TODO 대체)

#### [FG-03] ⚠️ 에이전트 50개 이상 시 레이아웃 심하게 축소

**파일:** `src/components/flow-graph/useFlowLayout.ts`
**위치:** 라인 108

**현재 코드:**
```typescript
const COLS = Math.min(3, sorted.length);  // 최대 3열 고정
```

**문제:** 에이전트가 많아질수록 세로로 길어지고 `fitToView()`가 전체를 맞추려고 극단적으로 축소함.

**수정 방법:** 에이전트 수에 따라 동적 열 수 계산.

```typescript
// 동적 열 수 계산 (에이전트 수에 따라)
const COLS = (() => {
  const n = sorted.length;
  if (n <= 6) return Math.min(3, n);
  if (n <= 20) return 4;
  if (n <= 40) return 5;
  return 6;
})();
```
