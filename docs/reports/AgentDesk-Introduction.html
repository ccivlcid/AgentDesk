문제Problem

다수의 AI 에이전트, 지금 무슨 일이 일어나고 있나요? Multiple AI agents running — but can you see what's happening?

  • ✖어느 에이전트가 어떤 태스크를 하는지 알 수 없다No visibility into which agent is working on which task
  • ✖Rules·Memory·Hooks가 어디에 적용되는지 파악 불가Can't tell where Rules, Memory, or Hooks are applied
  • ✖에이전트 간 협업 흐름을 추적할 방법이 없다No way to track collaboration flows between agents
  • ✖문제가 생겼을 때 어디서 왜 발생했는지 모른다When something breaks, it's impossible to trace where and why
  • ✖토큰 비용이 어디서 얼마나 소비되는지 볼 수 없다Token costs are invisible — no idea which agent is burning budget
  • ✖로컬 LLM·외부 지식베이스 연동이 제각각이다Local LLM and external KB integrations are fragmented and inconsistent
💡

AgentDesk의 답 AgentDesk's Answer

에이전트는 CLI 프로세스다.
프로젝트는 그 에이전트들이 일하는 OS다.
UI/UX는 그 OS의 컨트롤 패널이다. Agents are CLI processes.
The project is the OS those agents work within.
The UI/UX is the control panel for that OS.

에이전트 실행 상태·출력·의사결정·협업 흐름을 한 화면에서 실시간으로 모니터링 Monitor agent execution state, output, decisions, and collaboration flows — all in real time from a single screen
