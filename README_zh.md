# AgentDesk

**产品需求 — 概述**

AgentDesk 是一个 **项目 OS**：面向以 CLI 进程运行的 AI 代理的操作舱，在一个界面中管理项目、任务和代理团队，并提供消息集成与像素办公室视图。

---

## 概念

| 项目 | 说明 |
|------|------|
| **一句话概念** | **按自己的方式工作，拿到想要的结果** — 你（客户）定义项目、任务与代理，在一处管理执行流程与产出物。 |
| **设计概念** | **CLI 管理工具** 感（k9s、lazygit 风格）。深色终端调、等宽字体、⌘K 命令面板。执行视图采用终端输出风格。 |
| **口号 (EN)** | A Project Operating System Tailored to Your Workflow |
| **口号 (ZH)** | 贴合工作流的项目操作系统 |

---

## 1. 产品概述

| 项目 | 说明 |
|------|------|
| **愿景** | 贴合工作流的项目操作系统 — 在一个控制平面管理目标、风险、关卡与产出物。 |
| **定位** | CLI 代理管理工具（k9s/lazygit 风格），非通用仪表盘。 |
| **默认** | 深色主题、等宽字体、键盘优先（如 ⌘K 命令面板）。 |

---

## 2. 目标与成功

- **首要：** 运营人员可创建项目、将任务分配给代理，并在应用内追踪执行（终端日志、报告）。
- **次要：** 基于消息的指令（`$` / `!`）与决策收件箱流程；项目级团队与仪表盘四象限（目标、风险、关卡、产出物）。

---

## 3. 目标用户

- **首要：** 运行项目并协调 AI 代理的人（团队负责人、PM、小规模组织负责人）。
- **使用流程：** 创建/选择项目 → 仪表盘·任务看板·团队 → 运行代理 → 查看报告与产出物。

---

## 4. 范围内（主要功能）

| 领域 | 说明 |
|------|------|
| **仪表盘** | 项目概览、团队面板、代理活动、运维区块。 |
| **工作图** | 部门与代理的像素风办公室视图。 |
| **任务** | 看板、计划任务、产出物。 |
| **代理与团队** | 代理、部门、心跳监控；项目团队分配。 |
| **库** | 技能、代理规则、记忆、钩子。 |
| **CLI 使用量** | 使用量与成本视图。 |
| **设置** | API 提供商、OAuth、网关/消息、数据等。 |
| **消息** | Telegram、Discord、Slack 等；收件箱 Webhook；`$` 指令与 `!` 任务流程。 |

## 6. 要求与快速开始

**要求：** Node.js ≥ 22，pnpm ≥ 10

```bash
pnpm install
cp .env.example .env
pnpm setup
pnpm dev
```

在浏览器中打开 **http://localhost:8800**。

| 命令 | 说明 |
|------|------|
| `pnpm dev` | 启动开发服务 |
| `pnpm build` | 生产构建 |
| `pnpm test` | 运行测试 |
| `pnpm lint` | 代码检查 |
| `pnpm setup` | 初始化设置 |
